### 👨‍💻 About Me

I am a **Data Science student at Politeknik Elektronika Negeri Surabaya (PENS)** with a passion for **Applied Machine Learning & Backend Engineering**.

> *"I believe an accurate model isn't enough if nobody can use it. I build systems end-to-end: from data cleaning and modeling, to wrapping them in robust APIs and containerizing with Docker for real-world deployment."*

- 🎓 **Education**: Undergraduate in Applied Data Science, PENS (Semester 5)
- 💡 **Interests**: Machine Learning Pipelines, Backend Architecture, API Development, and LLM Applications
- 🚀 **Currently Building**: Production-ready data applications & scalable REST APIs
- 📍 **Based In**: Surabaya, Indonesia
